# Збірка АКБ 21700 — вебверсія для iPhone (PWA)

Та сама програма, що й для Windows: розрахунок S/P, підбір груп, нікелева стрічка, BMS і схема з двох торців.
На iPhone її ставлять іконкою на екран «Додому»: вона відкривається на весь екран і **працює без інтернету**.

```
public/   ← сайт (готовий, нічого збирати не треба)
tools/    ← build.py — перезбирає public/index.html з основної сторінки; icons.py — іконки
```

## Розгортання (як і карту): GitHub → Cloudflare Pages
1. На github.com створіть новий репозиторій, наприклад `akb21700` (можна приватний).
2. **Add file → Upload files** → перетягніть **вміст** цієї папки (`public`, `tools`, `README.md`) → **Commit changes**.
3. dash.cloudflare.com → **Workers & Pages → Create → Pages → Connect to Git** → оберіть репозиторій.
   - Framework preset: **None**
   - Build command: *(порожньо)*
   - Build output directory: **`public`**
4. **Save and Deploy** → отримаєте адресу на зразок `https://akb21700.pages.dev`.

## Встановлення на iPhone
1. Відкрийте адресу в **Safari**.
2. **Поділитися → На екран «Додому» → Додати**.
3. Запускайте з іконки «АКБ 21700». Після першого відкриття працює й без мережі.

## Оновлення
Змініть файли в репозиторії — Cloudflare викладе нову версію сам. На телефоні вона підтягнеться з другого запуску.
Якщо змінюєте основну сторінку, перезберіть: `python3 tools/build.py <шлях до index.html калькулятора> public`
(скрипт сам оновить список файлів і версію офлайн-кешу).

Дані, які ви вводите, зберігаються лише на цьому телефоні.
